# Prosess

## Arbeidsform
- Teamet bruker ukentlige møter og løpende arbeid mellom møtene.
- Oppgaver fordeles i GitLab Issue Board.
- Kode samarbeides via branches, merge requests og commit-historikk.

## Samarbeid
- Kommunikasjon skjer via Discord og fysiske møter.
- Ansvar fordeles etter delområder (meny, spilllogikk, elementer, spiller).
- Teamet følger en iterativ utviklingsstil med små inkrementer.

## Erfaring
- Tydelig oppgavefordeling gir god fremdrift.
- Tidlig integrasjon av kode reduserer merge-konflikter.
- Kontinuerlig oppdatering av dokumentasjon gjør innlevering enklere.
