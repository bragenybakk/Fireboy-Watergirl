# Brukerhistorier

## Historie 1: Bevegelse
Som spiller vil jeg kunne gå til venstre/høyre og hoppe, slik at jeg kan navigere brettet.

**Akseptansekriterier:**
- `A`/`Pil venstre` flytter spiller venstre.
- `D`/`Pil høyre` flytter spiller høyre.
- `Pil opp` utfører hopp.

## Historie 2: Meny og flyt
Som spiller vil jeg kunne navigere menyer med tastatur, slik at jeg kan starte eller avslutte spill uten mus.

**Akseptansekriterier:**
- `W/S` eller piltaster navigerer i menyer.
- `Enter` eller `Mellomrom` velger menypunkt.
- `Esc` går tilbake eller pauser/fortsetter avhengig av tilstand.

## Historie 3: Kollisjon og utfordring
Som spiller vil jeg møte hindringer og farer, slik at spillet blir utfordrende.

**Akseptansekriterier:**
- Spilleren stopper mot vegger/plattformer.
- Farlige elementer kan utløse game over.
- Spilleren kan starte på nytt via menyflyt.
